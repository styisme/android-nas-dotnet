# 终极使用与运维指南 (USAGE)

本指南是 Android NAS (.NET 版) 的官方第一手操作手册。无论你是刚接触 NAS 的萌新，还是追求极限压榨硬件性能的极客，都能在这里找到对应的实战操作步骤。

---

## 📱 一、 服务端部署与初始化

### 1.1 闲置安卓手机部署
将淘汰下来的旧安卓手机插上电源，连上 WiFi，它就能变成一台全天候的低功耗 NAS。

1. **安装应用**：下载并安装 `AndroidNas-Server-APK`（包名：`com.androidnas.next.server`）。
2. **授权三座大山**（缺一不可，否则会导致网络断开或无法读写文件）：
   - **通知权限** (Android 13+)：前台服务必须常驻通知栏，否则系统会在几秒内杀掉服务。
   - **所有文件访问权限** (Android 11+)：在设置中开启“所有文件访问权限”（即 MANAGE_EXTERNAL_STORAGE），赋予其读写 `/storage/emulated/0` 的权力。
   - **忽略电池优化** (Android 6+)：点击“忽略电池优化”，防止系统进入 Doze 休眠模式断开 Wi-Fi。
3. **启动服务**：打开 App，点击首页的「启动」按钮。状态栏出现 `Android NAS` 的常驻通知，即表示服务端已就绪。
4. **查看 IP**：记下首页显示的局域网 IP 地址（例如 `192.168.1.100`），后续客户端都需要连接这个地址。

### 1.2 PC 电脑端部署 (Windows / Linux)
如果你觉得手机存储太小，或者想直接在电脑上跑 NAS，我们提供了纯原生的控制台程序。

1. **下载运行**：下载 `AndroidNas-DesktopServer` 单文件程序（无需安装 .NET 环境，双击即用）。
2. **初始化**：控制台会首先询问你偏好中文还是英文。
3. **自动唤起**：服务端启动后，程序会自动调用系统默认浏览器打开 `http://localhost:8080`。你的电脑瞬间变成了一个拥有全盘文件访问权的 NAS。

## 🖥️ 二、 客户端连接与挂载指南

服务端跑起来后，局域网内的任何设备都可以通过以下方式接入：

### 2.1 浏览器直连 (Web UI)
直接在任何设备的浏览器中输入 `http://<服务端IP>:8080`。
- **默认账号**：`admin`
- **默认密码**：`admin`
- **功能**：网页版提供了最完整的控制台。可以在这里修改系统配置、开启极寒模式、在线解压 ZIP、进行局域网剪贴板同步。

### 2.2 WebDAV 挂载 (推荐：Windows 资源管理器 / Mac Finder)
我们将 WebDAV 服务跑在了 `8081` 端口，这是最适合日常像本地硬盘一样使用的协议。

- **Windows 挂载**：右键“此电脑” -> 映射网络驱动器 -> 输入 `http://<服务端IP>:8081` -> 输入账号密码。
- **Mac 挂载**：在 Finder 菜单栏选择“前往” -> “连接服务器” -> 输入 `http://<服务端IP>:8081`。
  > **⚠️ Windows 致命避坑**：由于微软的安全策略，Windows 默认拒绝通过 HTTP 发送 Basic Auth 密码。如果你发现一直提示密码错误或无法连接，必须修改注册表：
  > 1. 按 `Win + R` 输入 `regedit` 回车。
  > 2. 定位到：`HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\WebClient\Parameters`。
  > 3. 找到 `BasicAuthLevel`，将其值修改为 `2`（允许 HTTP 明文传输）。
  > 4. 重启 `WebClient` 服务（在服务管理器中重启，或在命令行输入 `net stop webclient` 然后 `net start webclient`）。

### 2.3 FTP 协议连接
我们在 `2121` 端口原生手写了 FTP 服务，兼容性极高，适合老旧设备或大批量文件传输。
- **主机**：`<服务端IP>`
- **端口**：`2121`
- **用户名**：`admin`
- **密码**：`admin`
- **客户端**：推荐使用 FileZilla、Total Commander，或者直接在 Windows 资源管理器地址栏输入 `ftp://<服务端IP>:2121`。

### 2.4 安卓客户端 (Client App)
1. 下载安装 `AndroidNas-Client-APK`（包名：`com.androidnas.next.client`）。
2. 打开应用，客户端会自动扫描局域网内的 NAS 服务端。
3. 如果自动扫描未果，可以手动输入 IP（默认端口 8080）及账号密码。
4. 连接成功后，你就可以在手机上浏览 NAS 上的文件、上传照片、播放视频了。

## ✨ 三、 核心玩法与极客功能详解

### 3.1 跨端投屏流转 (手机 -> TV)
无需任何 DLNA 或 Miracast 协议，我们自建了最极速的 UDP 投屏通道。
1. 确保电视安装并打开了 `AndroidNas-TV-APK`。
2. 在手机客户端（Client）中，进入文件列表。
3. 点击右上角「多选」按钮，勾选一个视频文件。
4. 点击底部的「投屏到 TV」。
5. **底层原理**：手机向局域网 `8090` 端口广播 `PLAY:<视频绝对URL>`，电视端监听到指令后，直接拉起系统原生播放器进行播放。

### 3.2 局域网剪贴板
- 在手机浏览器或手机客户端上复制一段长文本。
- 打开电脑的 Web UI，点击右上角的「剪贴板」图标。
- 直接按 `Ctrl+V`，文本即刻同步。该功能完全基于内存，重启服务端后清空，保证隐私绝对不出局域网。

### 3.3 配置秒级迁移 (Import / Export)
如果你换了新手机，或者想把服务端从手机迁移到 PC：
1. 在原设备的「设置」中，点击「导出配置」。系统会生成一个 `.json` 备份文件。
2. 在新设备上安装好服务端，点击「导入配置」，选择该文件。
3. 端口、密码、极寒模式等所有个性化设置瞬间同步，免去重新配置的烦恼。

### 3.4 多语言无缝切换
- **手机端**：驾驶舱设置页中，提供了 `zh-CN` 与 `en-US` 的下拉切换菜单，保存后整个 UI 瞬间改变。
- **PC 服务端/客户端**：控制台首次启动会询问语言，并记录在本地文件中，下次启动直接生效。

## ⚙️ 四、 高级驾驶舱与底层调优

在服务端的 Web UI 或手机 App 的「NAS 驾驶舱」中，有大量硬核设置：

### 4.1 端口修改
- **Web 端口**：默认 `8080`。
- **WebDAV 端口**：默认 `8081`。
- **FTP 端口**：默认 `2121`。
- **HTTPS 端口**：默认 `8443`。
*(修改后必须点击“保存并重启服务”才能生效。)*

### 4.2 自签 HTTPS 开启
如果你在公共网络下使用，建议开启 HTTPS：
- 打开「开启 HTTPS (自签)」开关。
- 服务端会在 `8443` 端口动态生成一张自签证书并启动加密监听。此时 HTTP 的 `8080` 端口依然保留，完美兼顾新旧设备。

### 4.3 极寒省电模式
如果你用的是很老的旧手机，电池已经鼓包或老化，请开启极寒模式：
- 开启后，底层会强制降低 `WakeLock` 的持有频率。
- **自动切断**内网穿透的长连接请求。
- **强制关闭** LocalSend 与 DLNA 广播（因为这些协议需要持续监听组播包，极其耗电）。

## 🦅 五、 极客进阶：Root 与远程控制

### 5.1 全盘 Root 模式
手机必须获取 Root 权限（Magisk）。
1. 在设置中开启「全盘 Root 模式」。
2. 此时服务端会通过 `su` 命令提权。
3. Web 界面、WebDAV、FTP 将直接突破 Android 沙盒，你可以浏览 `/data`、`/system` 等底层目录。

### 5.2 Web Shell 与 CLI 终端
- **Web 端**：在手机 App 或 Web 控制台中点击终端图标，直接输入 `ls -l /data` 等命令。
- **PC CLI 端**：在电脑端的 `DesktopClient` 交互终端中，输入 `exec reboot` 或 `exec pm list packages`，指令会通过 HTTP API 发送到手机端，通过 Root 执行并回传结果。
- **安全拦截**：为了防止误触，服务端内置了黑名单，一旦检测到 `rm -rf /`、`mkfs`、`reboot` 等指令直接拦截并返回 403。

### 5.3 免费与自定义内网穿透
在「内网穿透」页面：
- 启动 `Tunnl.gg`、`Serveo` 等免费节点，自动生成公网 HTTPS 访问链接。
- 支持自定义 SSH 反向隧道：填入你自建 VPS 的 IP、账号、密码与端口，即可建立长期稳定的加密隧道。

## 🚑 六、 深度故障排查 (FAQ)

### 6.1 局域网内其他设备搜不到 NAS / 无法访问
1. **检查网段**：确保手机和电脑连接的是同一个路由器的 Wi-Fi（避免手机连 5G，电脑连 2.4G 被路由器 AP 隔离）。
2. **检查防火墙**：Windows 电脑首次访问时，可能会弹出防火墙提示，请勾选“专用网络”并允许访问。
3. **IP 变动**：手机休眠重连后，IP 可能从 `192.168.1.100` 变成了 `.101`。建议在路由器里给手机绑定静态 IP，或者在 App 首页重新查看。

### 6.2 传输大文件时经常断开 / 速度极慢
1. **后台被杀**：检查手机系统设置，将 App 的电池策略设为“无限制”，并在多任务卡片中下拉锁定，防止被国产 ROM 清理。
2. **Wi-Fi 休眠**：确认 App 内的“静音保活”已开启，该功能会向系统注册一个假的音频播放任务，防止息屏后 Wi-Fi 休眠。
3. **FTP 模式**：如果 WebDAV 拷贝慢，尝试切换使用 FTP 客户端（如 FileZilla）进行传输。

### 6.3 WebDAV 提示“无法连接到网络位置”或“密码错误”
- 这是 Windows 的祖传 Bug（强制拒绝 HTTP 下的 Basic Auth）。请参考上文 **2.2 节** 修改注册表 `BasicAuthLevel` 并重启 WebClient 服务。

### 6.4 开启 HTTPS 后，浏览器提示“您的连接不是私密连接”
- 因为这是服务端动态生成的自签证书，未经过权威 CA 机构认证。在 Web 端点击“高级” -> “继续前往”即可。如果是在电视上连接，建议退回 HTTP 的 8080 端口。

### 6.5 点击投屏，电视端无反应
- 检查电视端 App 是否被杀后台。
- 检查路由器是否开启了“AP 隔离”导致 UDP 广播报文无法送达。

## ⌨️ 七、 PC 客户端 (DesktopClient) 命令大全

在电脑上运行 `DesktopClient` 单文件后，你将进入一个极客风格的交互终端：

| 命令 | 示例 | 说明 |
|---|---|---|
| `ls` | `ls` | 查看当前目录下的文件列表 |
| `cd <dir>` | `cd Movies` | 进入 `Movies` 目录 |
| `cd ..` | `cd ..` | 返回上一级目录 |
| `get <file>` | `get Inception.mp4` | 下载指定文件到电脑当前目录 |
| `exec <cmd>` | `exec reboot` | **特权**：在服务端执行 Root Shell 命令 |
| `help` | `help` | 查看帮助列表 |
| `exit` / `quit` | `exit` | 退出终端 |
